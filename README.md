# 🌐 Personal Portfolio Website

A responsive personal portfolio website designed to showcase my skills, projects, education, certifications, and contact information. The website provides a clean and professional interface for presenting my technical profile online.

## ✨ Features

* 📌 Professional introduction
* 👩‍💻 About Me section
* 🛠️ Technical skills section
* 🚀 Projects showcase
* 🎓 Education details
* 📜 Certifications section
* 📄 Resume section
* 📩 Contact section
* 📱 Responsive design for desktop, tablet, and mobile devices
* ✨ Smooth scrolling and interactive UI elements

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Lav1315-max/portfolio-website.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd portfolio-website
```

### 3. Run the website

Open `index.html` in your web browser.
